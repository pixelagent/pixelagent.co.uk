## About

Pixelagent is the personal portfolio and studio site of Nigel Morris — a designer, developer, and educator with over 20 years of experience building everything from interactive websites to immersive apps. The site showcases work across three areas: games, software tools, and websites.

Built with [Mobirise](https://mobirise.com).

## Games

Game development work built with **Three.js**, **Unity**, and **Blender**, focused on creativity, prototyping, and player engagement.

### Miracle Maker Prototypes

A collection of 3D browser-based game prototypes, each exploring a different aspect of interactive gameplay. All share the same core premise — a player navigating a 3D planet — but diverge in aesthetics and feature focus.

| Prototype | Description |
|-----------|-------------|
| [Landing](https://purna.github.io/miracle-maker/tests/landing.html) | Full-featured prototype with UI, inventory, quest log, and NPC interaction |
| [Fog](https://purna.github.io/miracle-maker/tests/fog.html) | Atmospheric fog rendering with depth and density tuning |
| [VFX](https://purna.github.io/miracle-maker/tests/vfx.html) | GPU-based particle system with gravity, lifetime, and colour rendering |
| [Day & Night](https://purna.github.io/miracle-maker/tests/day_night.html) | Orbital day/night cycle with dynamic lighting and a player torch |
| [Toon Shader](https://purna.github.io/miracle-maker/tests/toonshader.html) | Cel-shaded style with black outlines and MeshToonMaterial |
| [Dialogue](https://purna.github.io/miracle-maker/tests/whatsapp.html) | WhatsApp-style NPC dialogue and conversation flow |
| [Dust](https://purna.github.io/miracle-maker/tests/dust.html) | Movement-based dust particles and atmospheric ground-level effects |

[▶ Play Miracle Maker](https://purna.github.io/miracle-maker/)

### Pixel Apps

Browser-based creative tools for game design and development, requiring no installation.

| App | Description |
|-----|-------------|
| [Pixel Art App](https://purna.github.io/pixelArt/index.html) | 2D sprite editor for designing pixel art characters, icons, and tiles |
| [Pixel 3D App](https://purna.github.io/pixel3d/index.html) | 3D scene layout tool for blocking out game environments in the browser |
| [Pixel Audio App](https://purna.github.io/pixelAudio/index.html) | Audio effect generator for creating and previewing custom game sounds |
| [Pixel Isometric](https://purna.github.io/pixelIsometric/index.html) | Isometric grid designer for building top-down maps and level layouts |
| [Pixel Music App](https://purna.github.io/pixelMusic/index.html) | Browser-based music sequencer for composing looping game tracks |
| [Pixel Kanban App](https://purna.github.io/pixelKanban/index.html) | Drag-and-drop kanban board for managing game development tasks |
| [Pixel Pose App](https://purna.github.io/pixelPose/index.html) | Character posing tool for planning sprites, animations, and in-game stances |
