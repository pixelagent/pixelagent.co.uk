How to Use

  • Tap/Click empty cells to add notes
  • Tap/Click active notes to select them (keeps selection on repeated taps)
  • Long-press active notes (hold for 0.5s) to delete them - cell will flash red
  • Delete button in the selected note panel removes the selected note
  • Clear Selection button deselects without removing notes
  • Adjust velocity with the slider or use presets (Soft/Medium/Normal/Hard)
  • Apply bulk changes to all active notes at once
  • Humanize to add natural variation to velocities (more realistic)
  • Visual feedback: Height of color bar indicates velocity; yellow glow shows selection
  • Mobile friendly: Works with touch gestures and includes haptic feedback
