Usage Instructions:

  1. Select an object in the scene
  2. Click on the translate tool button (🔄 icon) or press 'G' key

    • Green arrow → Move along Y axis
    • Blue arrow → Move along Z axis
  4. Use rotate tool (🔄 icon) or press 'R' for rotation
  5. Use scale tool (🔄 icon) or press 'S' for scaling
