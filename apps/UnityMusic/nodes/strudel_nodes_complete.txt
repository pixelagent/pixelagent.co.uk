## Source Nodes

### Instrument
**Purpose:** Generate melodic sounds from sample libraries  
**Execution Stage:** source (priority 10)

```javascript
// Basic usage
s('piano')

// With variant selection
s('piano').n(0)      // first piano sample
s('piano').n('<0 1 2 3>')  // cycle through variants

// Full parameter example
s('kalimba')
  .n('0 2 4 7')
  .gain(0.8)
  .pan(0.5)
  .attack(0.01)
  .decay(0.3)
  .sustain(0.7)
  .release(0.5)
```

**Available Instruments:**
- **Percussion:** agogo, anvil, bongo, cabasa, cajon, clave, clap, conga, cowbell
- **Mallet:** balafon, glockenspiel, kalimba, marimba, vibraphone, xylophone
- **Strings:** folkharp, harp, psaltery, strumstick, wineglass
- **Winds:** harmonica, ocarina, recorder, sax, saxello, trainwhistle
- **Keyboards:** piano, fmpiano, kawai, organ, pipeorgan, super64
- **Synths:** sawtooth, sine, square, triangle
- **Bass:** bass0, bass1, bass2, bass3, bassfoo, bassdm

### DrumSymbol
**Purpose:** Generate drum sounds from classic drum machines  
**Execution Stage:** source (priority 10)

```javascript
// Basic drum hits
s('bd')        // bass drum
s('sd')        // snare drum
s('hh')        // closed hi-hat
s('oh')        // open hi-hat

// Select drum machine bank
s('bd').bank('RolandTR909')
s('bd').bank('RolandTR808')
s('bd').bank('RolandTR707')
s('bd').bank('AkaiLinn')

// Control decay time
s('bd').dec(0.3)    // short decay
s('bd').dec(1.5)    // long decay
```

**Available Drum Symbols:**
- `bd` - Bass Drum/Kick
- `sd` - Snare Drum
- `rim` - Rimshot
- `hh` - Hi-Hat (Closed)
- `oh` - Hi-Hat (Open)
- `lt` - Low Tom
- `mt` - Mid Tom
- `ht` - High Tom
- `rd` - Ride Cymbal
- `cr` - Crash Cymbal

### Note
**Purpose:** Create melodic patterns from note names  
**Execution Stage:** source (priority 10)

```javascript
// Scientific notation
note('c4 e4 g4')           // C major triad
note('c3 eb3 g3')          // C minor triad
note('<c4 d4 e4 f4 g4>')   // C major scale (alternating)

// With synthesizer
note('c4 e4 g4').s('sawtooth')
note('c4 e4 g4').sound('sine')

// Complex pattern
note('[c4, e4, g4]')       // random from triad
note('c4@3 e4')            // c4 held for 3 steps
```

### SoundPattern
**Purpose:** Create patterns from sound names  
**Execution Stage:** source (priority 10)

```javascript
// Basic pattern
s('bd sd hh oh')

// With rests and grouping
s('bd ~ sd ~')
s('bd [sd sd] hh')

// Alternation
s('<bd sd> hh')

// Parallel
s('[bd, hh*4]')
```

### SoundSynth
**Purpose:** Set synthesizer waveform type  
**Execution Stage:** source (priority 11)

```javascript
// Apply to note patterns
note('c4 e4 g4').s('sawtooth')
note('c4 e4 g4').sound('sine')
note('c4 e4 g4').s('square')
note('c4 e4 g4').s('triangle')
```

## Structural Nodes

### Stack
**Purpose:** Layer multiple patterns in parallel  
**Execution Stage:** structural (priority 20)

```javascript
// Basic stacking
stack(
  s('bd'),
  s('hh*4')
)

// Complex layering
stack(
  s('bd').struct('x ~ x ~'),
  s('sd').every(2, fast(2)),
  s('hh*8').gain(0.6)
)

// With child nodes
stack(
  s('bd'),
  s('sd'),
  s('hh')
).bank('tr909')
```

### Sequence (Cat)
**Purpose:** Play patterns one after another  
**Execution Stage:** structural (priority 20)

```javascript
// Sequential patterns
cat(
  s('bd sd'),
  s('hh oh')
)

// Alias
seq(
  s('bd*4'),
  s('sd*2'),
  s('hh*8')
)

// Different pattern lengths
cat(
  n('0 1'),
  n('2 3 4'),
  n('5 6 7 8')
)
```

### Group
**Purpose:** Group patterns with flexible combining  
**Execution Stage:** structural (priority 20)

```javascript
// Parallel grouping
group(
  s('bd'),
  s('sd')
).mode('parallel')

// Alternating grouping
group(
  s('bd sd'),
  s('hh oh')
).mode('alternate')
```

### Jux
**Purpose:** Split stereo channels with different transforms  
**Execution Stage:** structural (priority 25)

```javascript
// Basic stereo split
s('bd sd').jux(
  x => x,              // left channel
  x => x.pan(1)        // right channel
)

// Different speeds per channel
s('hh').jux(
  x => x.speed(1),
  x => x.speed(1.5)
)

// Pitch offset
n('0 2 4').jux(
  x => x,
  x => x.add(7)
)
```

## Effect Nodes

### Gain
**Purpose:** Control volume/amplitude  
**Execution Stage:** spectral (priority 60)

```javascript
s('bd').gain(1)              // normal
s('bd').gain(0.5)            // half volume
s('bd').gain(1.5)            // 50% louder
s('bd').gain('<1 0.8 0.6>')  // descending pattern
```

### Pan
**Purpose:** Control stereo positioning  
**Execution Stage:** space (priority 70)

```javascript
s('bd').pan(0)               // hard left
s('bd').pan(0.5)             // center
s('bd').pan(1)               // hard right
s('bd').pan('<0 1>')         // alternating L/R
s('bd').pan('sine.slow(4)')  // slow panning
```

### Speed
**Purpose:** Change playback speed (affects pitch)  
**Execution Stage:** pitch (priority 40)

```javascript
s('bd').speed(1)             // normal
s('bd').speed(2)             // double speed (octave up)
s('bd').speed(0.5)           // half speed (octave down)
s('bd').speed('<1 1.5 2>')   // varying speeds
```

### LPF (Low Pass Filter)
**Purpose:** Filter out high frequencies  
**Execution Stage:** spectral (priority 60)

```javascript
s('bd sd').lpf(500)          // very muffled
s('bd sd').lpf(2000)         // warm
s('bd sd').lpf(8000)         // open
s('bd sd').lpf('<500 1000 2000 4000>')  // sweeping
s('bd sd').lpf('sine.range(200, 3000).slow(2)')  // LFO sweep
```

### HPF (High Pass Filter)
**Purpose:** Filter out low frequencies  
**Execution Stage:** spectral (priority 60)

```javascript
s('bd sd').hpf(100)          // remove sub-bass
s('bd sd').hpf(500)          // thin out
s('bd sd').hpf(2000)         // very thin
s('bd sd').hpf('<100 500 1000>')  // progressive
```

### Delay
**Purpose:** Time-based echo effect  
**Execution Stage:** space (priority 70)

```javascript
s('bd sd').delay(0.125)      // eighth note delay
s('bd sd').delay(0.25)       // quarter note
s('bd sd').delay(0.5)        // half note
s('bd sd').delay('<0.125 0.25 0.5>')  // varying

// With feedback control
s('bd').delay(0.25).delayfb(0.3)   // light feedback
s('bd').delay(0.25).delayfb(0.6)   // moderate
s('bd').delay(0.25).delayfb(0.9)   // heavy
```

### Reverb
**Purpose:** Spatial ambience effect  
**Execution Stage:** space (priority 70)

```javascript
s('bd sd').reverb(0.2)       // small room
s('bd sd').reverb(0.5)       // medium hall
s('bd sd').reverb(0.8)       // large cathedral
s('bd sd').reverb('<0 0.3 0.6>')  // building
```

### Room
**Purpose:** Set reverb room size  
**Execution Stage:** space (priority 70)

```javascript
s('bd sd').room(0.2)         // small room
s('bd sd').room(0.5)         // medium hall
s('bd sd').room(0.8)         // large space
s('bd sd').room('<0 0.3 0.6 0.9>')  // growing
```

### Distort
**Purpose:** Harmonic distortion  
**Execution Stage:** spectral (priority 60)

```javascript
s('bd').distort(0.1)         // subtle warmth
s('bd').distort(0.5)         // moderate overdrive
s('bd').distort(0.9)         // heavy distortion
```

### Crush
**Purpose:** Bit reduction (lo-fi effect)  
**Execution Stage:** spectral (priority 60)

```javascript
s('bd').crush(16)            // clean (no reduction)
s('bd').crush(8)             // 8-bit retro
s('bd').crush(4)             // 4-bit lo-fi
s('bd').crush(1)             // extreme 1-bit
s('bd').crush('<16 8 4 2>')  // progressive reduction
```

### Shape
**Purpose:** Waveshaping distortion  
**Execution Stage:** spectral (priority 60)

```javascript
s('bd').shape(0.1)           // subtle enhancement
s('bd').shape(0.5)           // moderate shaping
s('bd').shape(0.9)           // heavy shaping
s('bd').shape('sine.range(0, 1).slow(4)')  // animated
```

### Vowel
**Purpose:** Formant filter (vowel sounds)  
**Execution Stage:** spectral (priority 60)

```javascript
s('bd').vowel('a')           // open 'ah'
s('bd').vowel('e')           // 'eh'
s('bd').vowel('i')           // bright 'ee'
s('bd').vowel('o')           // 'oh'
s('bd').vowel('u')           // dark 'oo'
s('bd').vowel('<a e i o u>')  // cycle vowels
```

## Rhythmic Transform Nodes

### Chop
**Purpose:** Time slicing for granular effects  
**Execution Stage:** rhythmic (priority 30)

```javascript
s('bd sd hh oh').chop(4)     // chop into 4 parts
s('bd sd hh oh').chop(8)     // chop into 8 parts
s('bd sd hh oh').chop(16)    // very granular
```

### Stutter
**Purpose:** Repeat events rapidly  
**Execution Stage:** rhythmic (priority 30)

```javascript
s('bd').stutter(2)           // double each event
s('bd').stutter(4)           // quadruple
s('bd').stutter(8)           // 8x (glitch effect)
s('bd').stutter('<2 3 4>')   // varying stutters
```

### Slow
**Purpose:** Slow down pattern  
**Execution Stage:** rhythmic (priority 30)

```javascript
s('bd sd hh oh').slow(2)     // half speed
s('bd sd hh oh').slow(4)     // quarter speed
s('bd sd hh oh').slow('<2 3 4>')  // variable
```

### Fast
**Purpose:** Speed up pattern  
**Execution Stage:** rhythmic (priority 30)

```javascript
s('bd sd').fast(2)           // double speed
s('bd sd').fast(4)           // quadruple speed
s('bd sd').fast('<2 3 4>')   // variable speed
```

### Struct
**Purpose:** Apply rhythmic structure  
**Execution Stage:** rhythmic (priority 30)

```javascript
s('bd sd hh').struct('x ~ x ~')  // on-off-on-off
s('hh').struct('x x x x ~ x x ~')  // complex rhythm
s('bd').struct('<[x*<1 2> [~@3 x]] x>')  // nested pattern
```

### Euclidean
**Purpose:** Generate euclidean rhythms  
**Execution Stage:** rhythmic (priority 30)

```javascript
s('bd').euclidean(3, 8)      // 3 hits in 8 steps
s('sd').euclidean(5, 16)     // 5 hits in 16 steps
s('hh').euclidean(7, 16, 2)  // 7 hits, rotated by 2
```

## Pitch Transform Nodes

### Rev (Reverse)
**Purpose:** Reverse pattern order  
**Execution Stage:** pitch (priority 40)

```javascript
s('bd sd hh oh').rev()       // plays oh hh sd bd
n('0 1 2 3').rev()           // plays 3 2 1 0
```

### Palindrome
**Purpose:** Play forward then backward  
**Execution Stage:** pitch (priority 40)

```javascript
s('bd sd').palindrome()      // plays bd sd sd bd
n('0 1 2').palindrome()      // plays 0 1 2 2 1 0
```

### Shuffle
**Purpose:** Randomly reorder events  
**Execution Stage:** pitch (priority 40)

```javascript
s('bd sd hh oh').shuffle()   // random order
s('bd sd hh oh').shuffle(42) // reproducible with seed
```

### Pitch (Note)
**Purpose:** Transpose by semitones  
**Execution Stage:** pitch (priority 40)

```javascript
note('c4 e4 g4').note(0)     // no change
note('c4 e4 g4').note(7)     // perfect fifth up
note('c4 e4 g4').note(-12)   // octave down
note('c4 e4 g4').note('<0 3 7 12>')  // major intervals
```

### Coarse
**Purpose:** Transpose by octaves  
**Execution Stage:** pitch (priority 40)

```javascript
note('c4').coarse(0)         // no change
note('c4').coarse(1)         // one octave up
note('c4').coarse(-1)        // one octave down
note('c4').coarse('<0 1 -1>')  // octave modulation
```

## Control Signal Nodes

### LFO (Low Frequency Oscillator)
**Purpose:** Generate modulation signals  
**Execution Stage:** modulation (priority 50)

```javascript
// Sine wave LFO
s('bd').lpf('sine.range(200, 2000).slow(4)')

// Saw wave LFO
s('bd').lpf('saw.range(200, 2000).slow(2)')

// Square wave LFO
s('bd').pan('square.slow(2)')

// Triangle wave LFO
s('bd').gain('tri.range(0.5, 1).slow(1)')
```

### Perlin Noise
**Purpose:** Smooth random modulation  
**Execution Stage:** modulation (priority 50)

```javascript
s('bd').lpf('perlin.range(500, 3000)')
s('bd').pan('perlin.range(-1, 1)')
s('bd').gain('perlin.range(0.7, 1)')
```

### Range
**Purpose:** Map control signal to min-max  
**Execution Stage:** modulation (priority 51)

```javascript
s('bd').lpf('sine.range(200, 3000).slow(2)')
s('bd').pan('perlin.range(-1, 1)')
s('bd').gain('rand.range(0.5, 1)')
```

### Random (Rand)
**Purpose:** Random values  
**Execution Stage:** modulation (priority 50)

```javascript
// Float random (0-1)
s('bd').gain('rand.range(0.5, 1)')

// Integer random
s('bd').n('irand(8)')         // 0-7
s('bd').n('irand(16)')        // 0-15

// Pattern random
s('bd').speed('[0.5, 1, 1.5, 2]')
```

### StepSeq
**Purpose:** Step sequencer  
**Execution Stage:** modulation (priority 50)

```javascript
// Basic step sequence
s('bd').lpf('stepseq("0 1 2 3", 4).range(200, 2000)')

// Complex pattern
s('bd').gain('stepseq("<0 2> <1 3>", 8).range(0.5, 1)')
```

## Wrapper Nodes

### Often
**Purpose:** Apply transform with high probability (70%)  
**Execution Stage:** wrapper (priority 80)

```javascript
s('bd sd').often(x => x.speed(2))
s('bd sd').often(x => x.gain(1.5))

// Custom probability
s('bd sd').often(0.8, x => x.fast(2))
```

### Sometimes
**Purpose:** Apply transform with medium probability (50%)  
**Execution Stage:** wrapper (priority 80)

```javascript
s('bd sd').sometimes(x => x.speed(2))
s('bd sd').sometimes(x => x.pan(1))

// Custom probability
s('bd sd').sometimes(0.6, x => x.rev())
```

### Rarely
**Purpose:** Apply transform with low probability (25%)  
**Execution Stage:** wrapper (priority 80)

```javascript
s('bd sd').rarely(x => x.speed(0.5))
s('bd sd').rarely(x => x.stutter(4))

// Custom probability
s('bd sd').rarely(0.1, x => x.chop(8))
```

### Every
**Purpose:** Apply transform every N cycles  
**Execution Stage:** wrapper (priority 80)

```javascript
s('bd sd hh oh').every(4, x => x.fast(2))
s('bd').every(2, x => x.speed(0.5))
s('hh*4').every(3, x => x.gain(1.5))
```

### Whenmod
**Purpose:** Apply transform when cycle mod matches  
**Execution Stage:** wrapper (priority 80)

```javascript
// Transform on cycles 6 and 7 of every 8
s('bd').whenmod(8, 6, x => x.fast(2))

// Transform on cycles 2 and 3 of every 4
s('sd').whenmod(4, 2, x => x.gain(1.5))
```

### Off
**Purpose:** Layer time-shifted transformation  
**Execution Stage:** structural (priority 25)

```javascript
// Echo effect with pitched-up copy
s('bd sd').off(0.25, x => x.speed(2))

// Quiet delayed copy
s('sd').off(0.125, x => x.gain(0.5))

// Harmony delay
n('0 2 4').off(0.5, x => x.add(7))
```

## Mini-Notation Quick Reference

### Basic Operators

```javascript
// Rest
s('bd ~ sd ~')               // silence on beats 2 and 4

// Hold/Tie
s('bd _ sd _')               // extend bd and sd

// Grouping (subdivision)
s('bd [sd sd]')              // two sd in second half
s('bd [sd [hh hh]]')         // nested subdivision

// Parallel (simultaneous)
s('[bd, hh*4]')              // bd with fast hi-hats
s('[bd sd, hh oh]')          // two rhythms at once

// Alternation (per cycle)
s('bd <sd rim>')             // alternates each cycle
s('<bd sd> hh')              // alternating kick pattern
```

### Repetition & Timing

```javascript
// Multiply (fast repeat)
s('bd*4')                    // repeat 4 times
s('hh*8')                    // 8 hi-hats
s('bd*<2 3 4>')              // varying repeats

// Divide (slow down)
s('bd/2')                    // every 2 cycles
s('hh/4')                    // every 4 cycles

// Replicate (pattern repeat)
s('bd!4')                    // repeat whole pattern 4x
s('[bd sd]!2')               // repeat sequence 2x

// Elongate (extend duration)
s('bd@2 sd')                 // bd lasts 2 steps
s('0@3 1')                   // 0 held for 3 steps
s('~@4 bd')                  // 4-step rest then bd
```

### Rhythmic Patterns

```javascript
// Euclidean rhythms
s('bd(3,8)')                 // 3 hits in 8 steps
s('sd(5,16)')                // 5 hits in 16 steps
s('hh(7,16,2)')              // 7 hits, rotated by 2

// Bjorklund (alternative syntax)
s('bd{3,8}')                 // same as bd(3,8)

// Probability
s('bd?0.5')                  // 50% chance each hit
s('hh?0.8')                  // 80% chance
s('sd?<0.3 0.7>')            // varying probability

// Degrade
s('bd:0.3')                  // randomly remove 30%
s('[bd sd]:0.2')             // degrade whole group
```

### Complex Patterns

```javascript
// Nested complexity
s('<[x*<1 2> [~@3 x]] x>')
// Outer alternation:
//   - First cycle: [x*<1 2> [~@3 x]]
//   - Second cycle: x
// Inner patterns:
//   - x*<1 2>: x repeated 1 or 2 times
//   - [~@3 x]: 3-step rest then x

// Multi-layer parallel
s('[[x*<1 2> [~@3 x]] x, [bd sd], hh*8]')
// Three simultaneous patterns:
//   1. Complex nested pattern
//   2. bd sd sequence
//   3. 8 hi-hats

// Polymeter (different lengths)
s('[c4 e4 g4, d4 f4 a4]')
// Both patterns same length but different notes

s('[[bd sd], [hh hh hh]]')
// Two-against-three polyrhythm
```

## Common Pattern Combinations

### Basic Drum Beat
```javascript
stack(
  s('bd').struct('x ~ x ~'),
  s('sd').struct('~ x ~ x'),
  s('hh*8').gain(0.6)
).bank('tr909')
```

### Filtered Bass Pattern
```javascript
n('0 3 7 10')
  .s('bass0')
  .lpf('sine.range(200, 2000).slow(4)')
  .gain(0.8)
```

### Evolving Melody
```javascript
note('c4 e4 g4 b4')
  .struct('<[x*<1 2> [~@3 x]] x>')
  .s('kalimba')
  .room('<0 .2 .4 .6>')
  .often(x => x.speed(1.5))
```

### Glitch Percussion
```javascript
s('rim cp')
  .sometimes(x => x.chop(8))
  .rarely(x => x.stutter(4))
  .delay(0.125).delayfb(0.5)
  .lpf('<500 2000>')
```

### Stereo Ambient Pad
```javascript
note('[c3, e3, g3]')
  .s('sawtooth')
  .jux(x => x, x => x.add(7))
  .attack(0.5).release(2)
  .lpf('perlin.range(500, 3000)')
  .reverb(0.8)
```

## Execution Stage Order

1. **source (10)** - Sound generators (Instrument, Drum, Note, s, n)
2. **structural (20)** - Combinators (stack, cat, seq, group)
3. **rhythmic (30)** - Time transforms (chop, stutter, slow, fast, struct)
4. **pitch (40)** - Pitch transforms (rev, palindrome, shuffle, note, coarse)
5. **modulation (50)** - Control signals (LFO, perlin, random)
6. **spectral (60)** - Filters & spectral (lpf, hpf, crush, shape, vowel, gain)
7. **space (70)** - Spatial effects (pan, delay, reverb, room)
8. **wrapper (80)** - Conditionals (often, sometimes, rarely, every, whenmod)

## Tips & Best Practices

### Performance Optimization
- Use `*` for fast repeats instead of writing out patterns
- Limit nesting depth in mini-notation to 4-5 levels
- Use wrapper nodes sparingly (they add CPU overhead)
- Prefer `slow()` over very large pattern strings

### Creative Techniques
- Combine `off()` with `add()` for instant harmonies
- Use `jux()` for instant stereo width
- Layer `struct()` patterns for complex polyrhythms
- Modulate filters with LFOs for movement
- Chain `sometimes()`, `often()`, `rarely()` for varied density

### Common Patterns
- **4/4 Kick:** `s('bd').struct('x ~ x ~')`
- **Backbeat Snare:** `s('sd').struct('~ x ~ x')`
- **Fast Hats:** `s('hh*8').gain(0.6)`
- **Euclidean Kick:** `s('bd').euclidean(3, 8)`
- **Filter Sweep:** `.lpf('sine.range(200, 3000).slow(4)')`

## Complete Example: Full Track

```javascript
stack(
  // Kick drum with structure
  s('bd').struct('<[x*<1 2> [~@3 x]] x>').bank('tr909'),
  
  // Snare with variation
  s('sd').struct('~ x ~ x').every(4, x => x.fast(2)),
  
  // Hi-hats with probability
  s('hh*8').gain(0.6).sometimes(x => x.speed(1.5)),
  
  // Bass line with filter
  n('[0 <1 3>]*<2!3 4>')
    .s('bass0')
    .lpf('sine.range(200, 2000).slow(4)'),
  
  // Melodic element
  note('c4 e4 g4')
    .s('kalimba')
    .room('<0 .2>')
    .often(x => x.add(7))
    .delay(0.25).delayfb(0.4)
)
```
