Case Study

Miracle Maker 3D

A comprehensive case study exploring browser-based game tool development with Three.js and Cannon-es physics. From prototype to production in 12 weeks.

The Challenge

Building Tools That Teach

The goal was to create a suite of educational game tools that demonstrate core game development concepts while remaining accessible to beginners. Each tool needed to be self-contained, performant, and visually engaging.

12 Weeks
8 Tools
The Solution

Modular Architecture

Each tool was built as a standalone HTML file with no build step required. Shared utilities were extracted into a common library, while tool-specific logic remained isolated. This enabled rapid iteration and easy comparison of approaches.

0 Build Steps
100% Browser Native
Results

measurable Impact

The tools have been used in classroom settings, game jams, and self-directed learning. Feedback indicates improved understanding of 3D concepts, physics simulation, and UI/UX principles among users of all skill levels.
